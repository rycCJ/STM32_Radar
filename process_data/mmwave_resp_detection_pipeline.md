# 毫米波雷达呼吸率检测算法流程详解

## 一、系统概述

本系统基于24GHz毫米波雷达（FMCW体制），通过采集人体胸腔因呼吸产生的微动位移信号，经信号处理流水线提取呼吸率（Respiration Rate, RR）。系统采样率50Hz，分析窗口30秒，输出单位为BPM（次/分钟）。

**核心流水线：**
```
原始Range Map → 静态杂波抑制 → 距离仓定位 → 相位提取与解缠 → 基线去除 → 带通滤波 → 频谱分析 → 呼吸频率估计 → 信噪比计算 → 多通道选择 → 呼吸率输出
```

---

## 二、逐步详解

### 步骤1：数据采集与缓冲

**实现方式：** 环形缓冲区（RingBuffer），容量30秒（1500帧@50Hz），逐帧输入距离维FFT数据。

**代码位置：** [`cplus/include/mmwave_struct.hpp:9-31`](cplus/include/mmwave_struct.hpp:9)

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 固定长度数组 | 简单但无法滑动更新 |
| 双缓冲交替 | 适合实时但内存翻倍 |
| 重叠滑动窗口 | 可提升时间分辨率，但计算量增大 |

**本方法优势：** 环形缓冲区自动覆盖最旧数据，实现滑动窗口无需数据搬移，内存效率高，天然适合流式实时处理。

---

### 步骤2：静态杂波抑制（均值滤波去直流）

**实现方式：** 对Range Map每列（距离维）计算均值，然后用原始数据除以均值（`demean`操作），消除静态物体回波干扰。

**代码位置：** [`cplus/src/mmwave_processing.cpp:891-925`](cplus/src/mmwave_processing.cpp:891)

**公式：**
```
demeaned[i][j] = range_map[i][j] / col_mean[j]
```

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 减均值（mean subtraction） | 简单但可能引入负值，对幅度调制信号不友好 |
| MTI滤波器（动目标指示） | 用延迟线对消，经典雷达方法，但设计复杂 |
| PCA去静态 | 自适应但计算量大，实时性差 |
| HPF高通滤波 | 去直流干净但可能损失低频呼吸信息 |

**本方法优势：** 除均值（归一化）方式同时抑制幅度和相位上的静态分量，保留微动信号的相对变化，对呼吸等微幅信号更友好；计算量极低（O(N)），适合嵌入式部署。

---

### 步骤3：距离仓定位（目标距离选择）

**实现方式：** 基于先验距离信息确定目标距离仓中心，在附近±N个bin范围内搜索幅值最大的距离仓，再取众数作为最终定位结果。

**代码位置：** [`cplus/src/mmwave_processing.cpp:176-211`](cplus/src/mmwave_processing.cpp:176)

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 全局最大能量法 | 简单但易受杂波干扰 |
| CFAR检测 | 雷达经典恒虚警方法，鲁棒但计算量大 |
| 多目标跟踪 | 适合多人体场景，复杂度高 |
| 深度学习定位 | 自适应但需标注数据，部署困难 |

**本方法优势：** 结合先验距离约束+局部搜索+众数投票，三重保障确保定位稳定性：先验距离缩小搜索范围避免误锁，局部搜索适应微小偏移，众数投票消除帧间抖动。

---

### 步骤4：相位提取与解缠

**实现方式：**
- **相位提取：** 对复信号取`arg()`提取瞬时相位
- **相位解缠：** 使用基于不连续性检测的unwrap算法（类似numpy.unwrap），修正2π跳变

**代码位置：** [`cplus/src/mmwave_processing.cpp:251-286`](cplus/src/mmwave_processing.cpp:251)

**Python版增强：** 使用扩展DACM（Extended Differentiated Phase Correction Method）解缠，基于IQ信号功率加权的差分相位累积，鲁棒性更强。

**代码位置：** [`py/src/nn_process.py:78-91`](py/src/nn_process.py:78)

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| Itoh差分法 | 简单但对噪声敏感，大位移易出错 |
| DACM | 基于差分相位，对幅度归一化，较鲁棒 |
| Extended DACM | 功率加权+滑动窗口平滑，最鲁棒 |
| Viterbi解缠 | 全局最优但计算量大 |
| 基于圆拟合的解缠 | 先拟合单位圆再提取弧长，精度高 |

**本方法优势：** C++版使用经典unwrap算法，计算高效适合嵌入式；Python版采用Extended DACM，通过功率加权抑制低信噪比区域的相位跳变，在体动干扰下仍能保持解缠连续性。

---

### 步骤5：基线去除（去趋势）

**实现方式：** 将解缠相位乘以物理缩放因子转化为微米位移（代码中`scaling_factor`），当前版本直接缩放（多项式拟合代码已注释保留）。

**代码位置：** [`cplus/src/mmwave_processing.cpp:288-336`](cplus/src/mmwave_processing.cpp:288)

**缩放公式：**
```
displacement(μm) = phase × c / (4π × f_start) × 10^6
```

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 多项式拟合去趋势 | 用8阶多项式拟合基线后相减，去除体动漂移 |
| 高通滤波 | 简单但可能损失呼吸低频分量 |
| 经验模态分解(EMD) | 自适应分解但计算量大，实时性差 |
| 小波去趋势 | 多尺度分析但需选小波基 |
| 中值滤波去基线 | 对尖峰鲁棒但窗口选择困难 |

**本方法优势：** 代码中保留了多项式拟合的完整实现（已注释），当前采用直接缩放方式保持信号完整性，避免过度处理引入失真。多项式拟合方案可随时启用以应对体动漂移场景。

---

### 步骤6：带通滤波（呼吸频段提取）

**实现方式：** 使用4阶Butterworth带通滤波器 + filtfilt零相位滤波。

- **呼吸滤波器参数：** 通带0.1~0.6 Hz（对应6~36 BPM）
- **心率滤波器参数：** 通带0.7~5.0 Hz（对应42~300 BPM）

**代码位置：** [`cplus/src/mmwave_processing.cpp:986-987`](cplus/src/mmwave_processing.cpp:986)，[`py/src/nn_process.py:32-33`](py/src/nn_process.py:32)

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| FIR滤波器 | 线性相位但阶数高，延迟大 |
| 切比雪夫滤波器 | 过渡带陡峭但通带波纹 |
| 小波滤波 | 时频自适应但计算量大 |
| 自适应滤波(LMS/NLMS) | 可跟踪时变频段但需参考信号 |
| 格型滤波 | 数值稳定但设计复杂 |

**本方法优势：** Butterworth滤波器通带平坦，不引入幅度失真；filtfilt零相位滤波消除相位延迟，保证呼吸波峰位置准确；4阶在性能和计算量间取得平衡，适合实时处理。

---

### 步骤7：频谱分析（FFT）

**实现方式：**
1. 对滤波后信号加Hanning窗抑制频谱泄漏
2. 补零至2048点提高频率分辨率
3. 执行Cooley-Tukey FFT
4. 仅保留0~5Hz频段（205个频率点）

**代码位置：** [`cplus/src/mmwave_processing.cpp:391-420`](cplus/src/mmwave_processing.cpp:391)

**频率分辨率：** 50/2048 ≈ 0.0244 Hz ≈ 1.46 BPM

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 周期图法(Welch) | 方差小但频率分辨率低 |
| MUSIC/ESPRIT | 超分辨率但计算量极大 |
| 自回归(AR)谱估计 | 短数据表现好但阶数选择困难 |
| 短时FFT(STFT) | 时频分析但窗口选择困难 |
| Chirp-Z变换 | 可在指定频段细化，灵活但复杂 |

**本方法优势：** FFT计算效率O(NlogN)，补零2048点实现约0.024Hz分辨率满足呼吸频率精度需求；Hanning窗有效抑制泄漏；仅保留0-5Hz减少计算量和存储。

---

### 步骤8：呼吸频率估计

**实现方式：** 在频谱中找最大峰值，然后向左右扩展至幅值降至最大值40%处，确定呼吸频率及带宽。

**代码位置：** [`cplus/src/mmwave_processing.cpp:431-476`](cplus/src/mmwave_processing.cpp:431)

**算法步骤：**
1. 找FFT幅度谱最大值对应频率 `rr_freq`
2. 向左扩展：幅值 ≥ 0.4 × max → `rr_freq_low`
3. 向右扩展：幅值 ≥ 0.4 × max → `rr_freq_high`
4. 呼吸率 = `rr_freq × 60`（BPM）

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 简单峰值检测 | 直接取最大峰，快速但易受噪声干扰 |
| 抛物线插值 | 对峰值附近三点插值，提高频率精度 |
| 谐波产品法 | 利用呼吸谐波叠加增强基频检测 |
| 自相关法 | 时域方法，对周期性信号鲁棒 |
| 时域峰值计数 | 数呼吸波峰个数，简单直观 |

**本方法优势：** 峰值+带宽扩展法不仅给出呼吸频率点估计，还给出频率置信区间（low/high），该带宽信息在后续心率计算中用于呼吸谐波排除，也在通道选择中作为质量指标。40%阈值在灵敏度和特异性间取得平衡。

---

### 步骤9：呼吸信噪比（SNR）计算

**实现方式：** 以呼吸频率为中心±0.05Hz范围定义为信号区，其余为噪声区，计算功率比（dB）。

**代码位置：** [`cplus/src/mmwave_processing.cpp:481-515`](cplus/src/mmwave_processing.cpp:481)

**公式：**
```
SNR(dB) = 10 × log10( signal_power_avg / noise_power_avg )
```

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 峰值/均值比 | 简单但未考虑带宽 |
| 频带能量比 | 指定频带vs全频带，灵活但需先验频带 |
| 信号位移幅度 | 时域方法，直观但受基线影响 |
| 谐波能量比 | 考虑谐波总能量，更全面 |
| MDL/AIC信息准则 | 统计方法但计算复杂 |

**本方法优势：** 以呼吸频率为中心的窄带信号功率与宽带噪声功率之比，物理意义明确；±0.05Hz窗口精确匹配呼吸信号带宽，避免噪声混入；dB值便于设置阈值和跨场景比较。

---

### 步骤10：多通道选择（最优距离仓选择）

**实现方式：** 在多个候选距离仓中，基于三重条件筛选最优呼吸通道：

**代码位置：** [`cplus/src/mmwave_processing.cpp:833-886`](cplus/src/mmwave_processing.cpp:833)

**筛选条件：**
1. **幅度条件：** 位移幅度 ≤ 1500μm，或（SNR ≥ 20dB 且幅度 ≤ 7500μm）
2. **带宽条件：** 频谱带宽（high-low）≤ 0.2Hz
3. **一致性条件：** 至少2个其他通道的呼吸率与当前通道差值 ≤ 6 BPM

满足以上三条件中SNR最大的通道被选中。

**其他可选方法：**
| 方法 | 说明 |
|------|------|
| 最大SNR选择 | 简单但可能选到杂波通道 |
| 最大幅度选择 | 直观但大幅可能是体动 |
| 加权评分法 | 灵活但权重需调优 |
| 聚类投票法 | 鲁棒但计算量大 |
| 深度学习选择 | 自适应但需标注数据 |

**本方法优势：** 三重条件联合筛选，从物理可行性（幅度）、频谱质量（带宽）、结果可靠性（一致性）三个维度保证选择质量，大幅降低误检率。一致性条件尤其关键——多个独立通道给出相近结果是最强的可靠性验证。
